## Publicar con GitHub Pages

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta (o haz `git push` tal como se indica más abajo).
2. En el repositorio, ve a **Settings → Pages**.
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. GitHub publicará el sitio en `https://<tu-usuario>.github.io/<nombre-del-repositorio>/`.

## Subir este contenido a GitHub desde cero

```bash
cd programacion-didactica-2026-2027
git init
git add .
git commit -m "Programación Didáctica 2026/2027 — Música de Cámara, Banda y Orquesta"
git branch -M main
git remote add origin https://github.com/<tu-usuario>/<nombre-del-repositorio>.git
git push -u origin main
```
